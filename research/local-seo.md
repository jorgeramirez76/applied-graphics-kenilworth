## On-page implementation (done in build)
- Unique `<title>` + meta description per page; canonical URLs; OpenGraph/Twitter cards; branded OG image.
- **Schema.org**: `LocalBusiness`/`ProfessionalService` (NAP, geo, hours, areaServed, aggregateRating, sameAs), `Service` per service, `FAQPage`, `BreadcrumbList`, `Review` on /reviews.
- Consistent **NAP** in header utility bar, footer, contact page, and schema — must exactly match Google Business Profile.
- Dedicated **/service-area** page (organized lists, no keyword stuffing) + service-area schema.
- Semantic headings, descriptive image `alt` text, mobile-first, fast (static export, optimized WebP, `next/image`).
- `sitemap.xml` + `robots.txt` (AI crawlers allowed — see AEO below).

## Off-page / profile actions (client to-do — in launch checklist)
1. **Claim & complete Google Business Profile** (primary lever for the map pack): correct categories (Sign shop, Vehicle wrapping service, Commercial printer), hours, photos, services, products, and Q&A.
2. Ensure **NAP consistency** across BBB, Yelp, Bing Places, Apple Maps, YellowPages, chamber, Alignable, PRINTING United directory — fix any "718 Jefferson" vs "718 B Jefferson" variants.
3. **Generate fresh Google reviews** (the public set is from 2017) and respond to them.
4. Build local citations/links: Kenilworth & Union County chambers, NJ business directories, supplier (3M) locator.
5. Add a location/keyword-relevant blog or project case studies over time (each wrap = a content opportunity).

## AEO / LLMO (AI answer engines)
- FAQ schema + concise, factual answers help eligibility for AI Overviews and assistant citations.
- `robots.txt` explicitly allows GPTBot, OAI-SearchBot, PerplexityBot, ClaudeBot, Google-Extended so the brand can be surfaced/cited.
- Keep a clear, factual "about" and services description (entity clarity) so AIs disambiguate the Kenilworth company from the Amesbury, MA "Applied Graphics."

## Measurement
Set up Google Search Console + GA4 (or a privacy-friendly analytics) at launch; track "near me"/geo queries, map-pack impressions, and quote-form conversions.
