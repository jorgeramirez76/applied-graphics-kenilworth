# Applied Graphics Inc. — Website

A premium marketing website for **Applied Graphics Inc.**, the 3M-certified vehicle-wrap and large-format graphics company in **Kenilworth, NJ** (`appliedgrafx.com`). Built with Next.js, TypeScript and Tailwind CSS, with full SEO metadata and Schema.org markup.

> **Built from verified public sources only.** Company facts, services, reviews and projects trace to documented sources in [`/research`](./research). Nothing was fabricated. Every project photo is flagged **"needs permission"** until Applied Graphics confirms image rights — see the [Pre-Launch Checklist](#-pre-launch-checklist).

---

## Tech stack
- **Next.js 14** (App Router) · **React 18** · **TypeScript**
- **Tailwind CSS** (custom industrial-premium theme)
- **Framer Motion** (scroll/interaction motion) · **lucide-react** (icons)
- **sharp** (build-time image optimization)
- Content-driven from `/data/*.json` — easy for a non-developer to edit

## Quick start
```bash
npm install         # install dependencies
npm run images      # (optional) re-process /assets/raw -> /public/images + brand art
npm run dev         # start dev server  ->  http://localhost:3000
npm run build       # production build
npm run start       # serve the production build
npm run lint        # lint
```
Node 18.18+ (or 20+) recommended.

## Editing content (no code required)
- **Business info / hours / phone:** `data/site-settings.json`
- **Services:** `data/services.json`
- **Portfolio:** `data/projects.json` (set `image`, `client`, `permissionStatus`)
- **Reviews:** `data/reviews.json`
- **Industries / clients:** `data/clients.json`
- **Service area towns:** `data/service-areas.json`

### Adding/replacing project photos
1. Drop high-resolution originals in `assets/raw/`.
2. Add an entry (slug → filename) in `scripts/process-images.mjs` `MAP`.
3. Run `npm run images` → optimized WebP lands in `public/images`.
4. Reference it in `data/projects.json` and set `permissionStatus` to `verified` once rights are confirmed.

## Going live (wiring the quote form)
The quote form posts to `src/app/api/quote/route.ts`, which currently **validates and logs**. Before launch, connect it to email/CRM (one of):
- **Resend** / **SendGrid** (add API key, send to Applied Graphics' inbox), or
- **Formspree** / **Web3Forms** (no backend), or
- Applied Graphics' existing GoDaddy form / inbox.

Look for the `--- WIRE THIS UP AT LAUNCH ---` comment in the route. Then enable real file upload for the artwork field.

## Deploy to Vercel
1. Push this folder to a GitHub repo.
2. In **Vercel → New Project**, import the repo (framework auto-detected as **Next.js**).
3. Set environment variable **`NEXT_PUBLIC_SITE_URL`** to the final domain (e.g. `https://www.appliedgrafx.com`) so canonicals, sitemap, OG and schema use the right host.
4. Deploy. Add the custom domain in **Vercel → Settings → Domains** and update DNS.
> No other env vars are required for the demo. Add your email-provider key when wiring the form.

Alternatively `npm run build` works for any Node host.
